# GhostProtocol

Fresh starter project with a runnable Playwright demo.

## Get started
```bash
npm install
npm start
```

Override the target URL:
```bash
GHOST_TARGET_URL="https://example.com" npm start
```

## What it does
- Builds TypeScript to `dist/` automatically before running.
- Launches a headless browser and prints the page title.

## Next steps
- Add your own automation logic in `src/index.ts`.
- Expand to multiple pages, data extraction, and proxy configuration.
